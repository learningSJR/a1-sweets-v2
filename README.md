# A1 Sweets V11
Independent Next.js 14 project. npm install, npm run dev, npm run build.
The loader is a short timed intro, not a network progress measurement. Hero uses manual slide controls. Scroll sequences use Framer Motion and 2D image layers, not 3D models. The photo-to-doodle reveal uses a generated edge-art derivative of the same photograph. Reduced-motion mode disables pinned sequences. Verify menu, contact details, images and business hours before publishing. Production build not run in this environment.

Version 12: responsive WaveDivider component between all major sections; full-width colour backgrounds. Hero divider follows the active slide.
